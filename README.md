# Inbox to MD (メモ整理アプリ)

ローカルのMarkdownメモをAI (Gemini) が自動的に分類・整理するアプリケーションです。
書きなぐったメモを、設定した「整理ルール（ワークフロー）」に従って適切なフォルダ・ファイルへ振り分けます。

## 特徴
- **3ペインUI**: ファイルツリー、エディタ、Markdownプレビューの3ペイン構成。
- **自動保存**: 入力内容は一定間隔で自動保存されます。
- **AI連携**: Gemini APIを使用して、1つのメモを複数の視点で同時に分類・処理できます。
- **非破壊処理**: 処理済みの元のメモは `archive/` フォルダにバックアップされるため、データ消失のリスクがありません。

## セットアップ手順

1. **要件**
   - Python 3.8以上推奨
   - `pip`

2. **依存パッケージのインストール**
   ターミナルを開き、本プロジェクトのルートディレクトリで以下を実行します。
   ```bash
   pip install -r requirements.txt
   ```

3. **起動**
   ```bash
   python app.py
   ```
   コンソールに表示されたURL（通常は `http://localhost:5000` または `http://127.0.0.1:5000`）にブラウザでアクセスします。

4. **APIキーの設定**
   - 画面左上の「⚙️ 設定」ボタンをクリックします。
   - ご自身の「Gemini API キー」を入力し、保存してください。

## 使い方

1. **メモの作成**
   - 中央ペインの「エディタ」にメモを書きなぐります。
   - ヘッダーの「📄 新規 ▼」ボタンから新しいメモを作成することも可能です。

2. **整理ルールの追加 (フォルダ管理)**
   - 「⚙️ 設定」画面から「新規ルール追加」を行います。
   - ルールの「保存先フォルダ名」と「プロンプト指示」を設定します。
   - プロンプトには、「どのようにメモを要約・抽出・分類するか」を記述してください。

3. **整頓の実行**
   - 画面右上の「✨ 整頓」ボタンをクリックします。
   - 対象のメモを選択して「実行する」を押すと、AIが自動でメモを解析し、各ルールの保存先フォルダにファイルとして出力・追記します。
   - 処理が完了すると元のメモは `archive/` フォルダへ移動します。

## ローカルファイル操作に関する注意点
- **ファイルの追加**: `data/inbox/` などのフォルダへローカル環境から直接Markdownファイルを追加・編集しても問題ありません。
- **フォルダ名の変更**: アプリ内で設定した「整理ルール（ワークフロー）」のフォルダ名を変更する場合は、必ず**本アプリの「⚙️ 設定」画面から行ってください**。設定画面から変更することで、ローカル上の物理フォルダ名も自動で追従（リネーム）されます。OS側から直接フォルダ名を変更すると、アプリ側で認識できなくなる場合があります。
